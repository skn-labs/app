# F-02 카탈로그·내 화장품 요구사항

[Feature #158](https://github.com/skn-labs/app/issues/158)

## P0

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| PRD-01 | 사용자는 제품명으로 카탈로그를 검색하고 제품 상세에서 `내 화장품에 추가하기`를 실행한다. 검색 결과는 커서 단위로 불러와 목록 하단에 닿으면 다음 페이지를 자동으로 보여준다. 추가만으로 루틴이나 사용 경험은 시작되지 않는다. | 제품이 많아져도 첫 화면과 스크롤을 가볍게 유지하고 보유·실제 사용을 분리한다. |
| PRD-02 | 내 화장품의 `+`는 탐색으로 이동한다. 가진 제품을 누르면 제품 정보와 AI 질문으로 이어가며, 제품 상세에는 보유 추가 외의 사용 방식 선택을 두지 않는다. | 제품 추가 경로를 탐색 한 곳으로 모으고 제품 상세의 불필요한 분기를 없앤다. |
| CAT-01 | 버전이 확인되지 않은 제품도 이름과 사용 사실은 남기되 공식 사실·성분 근거에는 쓰지 않는다. | 기록을 막지 않고 거짓 제품 사실을 피한다. |
| CAT-05 | 제품 상세는 먼저 `무슨 제품인지`, `루틴의 어느 단계인지`, `어떤 방식으로 사용하는지`를 설명한다. AI 요약은 제품별 카탈로그 설명과 특징을 사용하고 상단의 제품명을 반복하지 않는다. 입력에 없는 내용을 만들지 않으며, 출처 미확인 카탈로그 입력은 확인 사실·추천·Rescue 근거로 표시하지 않는다. 값이 없는 섹션과 관찰 과제는 숨긴다. | 같은 카테고리의 고정 문장을 피하면서 제품 설명과 확인 사실의 경계를 보존한다. |
| CAT-06 | 카탈로그 브랜드명이 보이는 UI는 저장소에 등록된 로고와 브랜드명을 함께 표시한다. 직접 등록 브랜드도 검증된 브랜드명과 정확히 일치할 때만 같은 로고를 쓴다. 로고가 없거나 불러오지 못해도 브랜드명과 중립 대체 마크를 유지하며, 브랜드를 법적 제조사로 바꾸어 부르지 않는다. | 식별성을 높이면서 브랜드·제조사·소유 회사를 잘못 합치는 표시를 막는다. |

## P1

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| CAT-02 | 브랜드·제품명·시장·용량·처방·패키지 단서가 같은 출시판을 식별한다. | 다른 버전의 정보가 섞이지 않게 한다. |
| CAT-03 | 제품 사실은 확인 당시 외부 snapshot을 참조하고 출처 종류·시각·원문 hash를 보존한다. | 과거 AI 설명을 재검증한다. |
| PRD-04 | 제품 삭제 후에도 과거 경험의 표시 이름과 참조 무결성을 보존한다. | 개인 이력을 끊지 않는다. |
| PRD-03 | 사용자는 제품별 메모를 경험 기록으로 전환하거나 단순 메모로 남길 수 있다. AI 사용 여부를 명시한다. | 비정형 기록의 의미와 사용 권한을 구분한다. |

## P2

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| PRD-05 | 영수증 OCR 후보는 사용자가 확인한 제품만 내 화장품에 추가한다. | 제품 검색 불편이 확인된 뒤 제공한다. |
| CAT-04 | 가격·판매처·확인 시각을 표시하되 AI 판단 순위에는 쓰지 않는다. | 구매 편의와 추천 독립성을 분리한다. |
