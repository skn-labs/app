# F-01 계정·데이터 경계 요구사항

[Feature #157](https://github.com/skn-labs/app/issues/157)

## P0

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| ACC-01 | 사용자는 아이디와 비밀번호로 가입·로그인하고 자기 제품·루틴·경험·패턴·대화에만 접근한다. | 개인 기록이 섞이면 모든 패턴과 탐색 결과가 무효다. |
| ACC-02 | 사용자는 계정과 연결 데이터를 영구 삭제할 수 있다. | 민감할 수 있는 피부·사용 경험에 필요한 통제다. |
| ACC-03 | 가입 후 온보딩은 현재 제품을 선택적으로 담고, `제품 하나` · `현재 루틴` · `먼저 탐색` 중 시작 방식을 고른다. 입력을 마친 뒤에는 `탐색 → 사용 → 기록 → 연결 → 다음 탐색`을 소개하고 마지막 단계에서 실제 사용 경험을 시작한다. 과거 제품과 피부 설문은 강제하지 않으며 완료 상태는 재접속 후에도 유지한다. | 콜드스타트 비용을 낮추면서도 첫 개인 데이터, 제품의 핵심 순환, 다음 행동을 한 흐름으로 이해시켜야 한다. |

## P1

없음.

## P2

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| ONB-01 | 자연어 선호·피하고 싶은 사용감은 선택적으로 받고 건너뛰기와 `잘 모르겠어요`를 제공한다. | 구조화된 실제 경험이 쌓이기 전의 약한 맥락으로만 쓴다. |
| MEM-01 | 사용자는 AI가 보존한 범용 맥락을 조회·수정·삭제한다. | 범용 기억 기능을 실제로 도입할 때 필요한 통제다. |

온보딩 마지막 단계(`설정 3 / 3 · 선택`)에서 받고 `user_preference`에 저장한다. 아무것도 고르지 않으면 행을 만들지 않아 `건너뜀`과 `답했지만 비움`을 구분한다. 이후 `/api/v1/me/preferences`로 조회·수정한다.

> 연령·성별·피부 타입 같은 고정 속성은 받지 않는다. ACC-03의 `피부 설문은 강제하지 않는다`와 [제품 규칙](../product/product-rules.md) 10항 `피부 타입·원인·영구 선호로 확정하지 않는다`에 따른 경계다.
