# 앱 내비게이션과 화면 역할

SKN의 주요 내비게이션은 사용자가 `현재 경험 → 보유 제품과 사용 맥락 → 실제 루틴 → AI 대화`를 서로 다른 개념으로 이해하게 해야 한다. 같은 데이터를 여러 대시보드에서 반복하지 않고, 각 화면은 하나의 주된 질문에 답한다.

## 주요 화면

| 화면 | 사용자의 질문 | 책임 | 포함하지 않는 것 |
| --- | --- | --- | --- |
| 홈 | 지금 무엇을 확인하고 다음에 무엇을 할까? | 확인 중인 경험, 바로 기록하기, 최근 패턴과 다음 탐색 진입 | 전체 제품 관리, 루틴 편집 폼 |
| My Lab | 내가 가진 제품을 지금 어떻게 쓰고 있나? | 내 화장품, 확인 중인 경험과 현재 루틴의 분리 표시, 제품 탐색 진입 | 경험 전체 타임라인, AI가 만든 적합 판정 |
| 루틴 | 실제로 어떤 조합을 사용하고 있나? | 현재 루틴과 비교 기준, 제품 순서·시간·빈도, 새 버전 편집 | 보유 추가만으로 루틴 자동 변경 |
| AI | 내 기록과 제품 정보를 무엇을 근거로 연결했나? | 일반·제품·패턴·Rescue가 이어지는 공통 대화 | 별도 기능마다 분리된 챗봇 |

프로필과 기록은 전역 탭이 아니라 상단 프로필 진입에서 연다. 사용자의 자기보고 프로필, 원본 경험, 근거가 있는 패턴과 계정 통제를 한곳에서 다루기 때문이다.

알림함은 전역 탭이 아니라 주요 화면의 상단 종에서 연다. 사용자가 지금 확인할 사건만 모아 보여주고, 각 알림은 경험 기록·패턴·프로필·제품 탐색의 원래 화면으로 돌아간다.

## 하위 흐름

- **제품 탐색**은 My Lab의 `+` 또는 홈의 탐색 행동에서 시작하는 집중 흐름이다. 제품을 추가해도 현재 루틴은 바뀌지 않으며 완료 뒤 My Lab으로 돌아갈 수 있다. 루틴 편집에서 시작했다면 저장해 둔 초안으로 복귀한다.
- **연구 흐름**은 My Lab에서 들어가는 하위 화면이다. 확인 중인 경험, 현재 루틴, 비교 기준과 최근 기록을 시간 관계로 자세히 보여준다. 별도 주요 탭으로 두지 않는다.
- **경험 기록**은 현재 경험이나 제품 하나에서 바로 시작한다. 7일 전에도 기록할 수 있고, 완료 뒤 홈·패턴·Rescue 중 결과에 맞는 다음 행동을 제공한다.
- **루틴 편집**은 현재 루틴을 덮어쓰는 화면이 아니라 새 버전과 새 경험을 만드는 집중 흐름이다.
- **알림함**은 읽음과 행동 완료를 구분하는 집중 흐름이다. 읽거나 미뤄도 7일 회고 시점과 경험 상태는 바뀌지 않으며, 사용자가 알림의 행동을 완료했을 때만 완료 상태가 연결된다.

## 상태 표현

홈과 My Lab은 아래 두 상태를 항상 다른 이름과 영역으로 표시한다.

1. `확인 중인 경험`: 일정 기간 사용감을 남기는 제품 또는 조합
2. `현재 사용 루틴`: 실제로 계속 사용하는 제품 조합

확인 중인 경험이 끝나도 현재 루틴은 유지된다. 비교 기준 루틴은 적합성·안전 판정이 아니라 Rescue에서 변경 전후를 복원하는 별도 맥락이다.

## 디자인 영향

- 주요 탭에서는 브랜드 헤더와 동일한 하단 내비게이션을 쓴다.
- 탐색·제품 상세·AI 대화·기록·편집은 뒤로가기 또는 명시적인 닫기를 가진 집중 흐름으로 연다.
- 주요 화면 헤더의 알림 종은 읽지 않은 노출 가능 알림이 있을 때만 점을 표시한다.
- 카드 그림자는 핵심 행동이나 겹쳐진 내비게이션처럼 실제 높이 구분이 필요한 곳에만 사용한다. 일반 정보 묶음은 선과 배경 차이로 계층을 만든다.
- 빈 상태는 설명에서 끝나지 않고 해당 화면의 책임에 맞는 한 가지 다음 행동을 제공한다.
