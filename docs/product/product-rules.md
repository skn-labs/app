# 제품 규칙과 AI 경계

## 용어

- **내 화장품**: 사용자가 보유하거나 사용한 제품 전체다.
- **루틴**: 특정 사용기간의 제품·아침/저녁·순서·빈도 조합이다.
- **사용 경험**: 제품 하나 또는 루틴을 쓰며 사용자가 느끼고 말한 만족·아쉬움·사용감·조합·변화·피부 반응이다.
- **비교 기준 루틴**: 사용자가 실제 사용과 불편 없음을 확인한 가장 최근 루틴이다. Rescue의 변경 비교에만 우선 사용한다.
- **내 패턴**: 둘 이상의 관련 경험에서 반복된 표현을 AI가 연결한 해석이다. 원본 근거와 반대 기록을 가진다.
- **AI Rescue**: 불편 경험에서 이어져 변경점과 보수적인 다음 루틴을 정리하는 같은 AI 채팅의 모드다.

## 반드시 지킬 규칙

1. 제품 등록은 루틴을 자동으로 바꾸지 않는다.
2. 루틴의 제품·시간대·순서·빈도 변경은 과거를 덮지 않고 새 버전을 만든다.
3. 경험 원문은 AI 요약과 분리해 보존한다.
4. 만족·아쉬움·모름과 불편 여부를 하나의 성공/실패 enum으로 합치지 않는다.
5. 7일은 경험 회고의 기본 due다. 의학·안전·효능 기준이나 루틴 합격 시험으로 표현하지 않는다.
6. 사용자는 7일 전에도 제품 경험·루틴 경험·불편 경험을 남긴다.
7. 비교 기준 루틴은 사용자가 실제 사용과 불편 없음을 명시한 경우에만 갱신한다.
8. 비교 기준은 루틴 전체의 관찰이며 제품별 적합 판정이 아니다.
9. 패턴은 연결된 원본 기록, 근거 건수, 반대 기록과 불확실성을 보여준다.
10. 한 번의 경험이나 AI 추론을 피부 타입·원인·영구 선호로 확정하지 않는다.
11. 제품 탐색은 닮은 경험·다른 점·현재 조합에서 볼 점·정보 부족을 설명하고 적합·안전·효능을 보장하지 않는다.
12. Rescue는 원인이나 범인을 확정하지 않고 사용자가 승인하기 전 루틴을 바꾸지 않는다.
13. 제품 정보가 없거나 버전이 불확실하면 `정보 부족`으로 남긴다.
14. `잘 모르겠어요`와 건너뛰기는 모든 경험·AI 질문에서 유효하다.
15. 온보딩 피부 프로필은 사용자가 직접 고른 자기보고 맥락이다. AI 추론·진단·원인 판정과 구분하고 사용자가 다시 조회·수정할 수 있게 한다.
16. 카탈로그의 브랜드명과 로고는 제품 식별을 위한 표시다. 브랜드를 법적 제조사·소유 회사·OEM/ODM으로 바꾸어 부르거나 제품 이미지 도메인에서 로고를 추론하지 않는다.
17. 루틴의 AI 문장은 개인 기록과 자기보고 선호를 바탕으로 한 읽기 전용 해석이다. 사용자의 목표나 피부 사실로 확정하지 않고, 해당 루틴 버전과 함께 보존하며 생성 실패가 루틴 저장을 막지 않는다.

## AI와 서버

| AI | 서버 |
| --- | --- |
| 자연어 원문에서 사용자가 말한 관찰을 구조화한다. | 원문과 구조화 결과를 분리하고 같은 사용자 소유권을 보장한다. |
| 질문과 관련된 개인 경험을 연결하고, Responses API의 `web_search`로 외부 자료를 검색한다. | 정확한 제품 식별정보·현재 루틴·비교 기준 루틴·관련 사용 결과만 제공하고 실제 ID와 접근 권한을 검증한다. |
| 패턴 후보·반대 기록·정보 부족을 설명한다. | 최소 근거 조건, schema와 참조 무결성을 검증한다. |
| 필요한 후속 질문과 Rescue 제안을 만든다. | 상태 전이와 사용자 승인, 멱등성을 통제한다. |

AI가 만든 구조화 값과 패턴은 `model`, `prompt`, `schema version`, 입력 snapshot과 원본 근거를 추적한다. 사용자가 수정한 원문은 새 revision으로 보존하고 관련 패턴을 다시 계산한다.

## 패턴 생성 규칙

- P0에서 같은 또는 의미상 가까운 관찰이 서로 다른 경험 2건 이상에 있어야 패턴 후보로 노출한다.
- 제품 하나의 반복 기록과 서로 다른 제품의 반복 기록을 구분해 표시한다.
- 반대되는 경험이 있으면 숨기지 않고 함께 표시한다.
- 근거가 1건이면 패턴이 아니라 `이번 기록에서 나온 관찰`로 표시한다.
- 패턴은 추천 순위를 직접 결정하는 점수가 아니라 AI 탐색이 참조하는 개인 근거다.
- 사용자는 패턴에서 연결된 원문으로 이동하고 `관련 없음`을 표시할 수 있다.

## 제품 사실과 외부 근거

- 매 질문의 외부 검색은 P1 제품 공식정보, P2 공공기관, P3 연구 자료, P4 보조 자료 순서로 선택한다.
- P4 판매 페이지·블로그는 식별·사용 맥락 보조로만 쓰고 안전·효능·원인 판단 근거로 쓰지 않는다.
- AI 답변에 실제로 사용한 OpenAI `url_citation`만 HTTPS URL·제목·우선순위와 함께 메시지에 저장하고 문장 끝에서 클릭할 수 있게 표시한다.
- 반복 사용이 필요한 정적 제품 사실을 카탈로그에 승격할 때에는 별도 snapshot과 hash를 보존한다.
- 원료 연구를 완제품 효과로 확대하지 않는다.
- 리뷰·인기·판매량은 제품 사실 근거로 사용하지 않는다.
- 외부 근거와 개인 경험을 같은 문장 안에서 혼합해 출처를 흐리지 않는다.

## 의료 경계

- 질환·알레르기·원인·응급도·진료과를 판단하지 않는다.
- 심하거나 빠르게 악화된다는 사용자 표현이 있으면 제품 순위와 루틴 제안을 중단하고 전문가 확인을 권한다.
- 안전 안내 뒤에도 사용자 원문은 보존하되 AI가 의료 해석을 추가하지 않는다.

## 공통 AI 채팅 UX

- 제품 질문, 패턴 질문과 Rescue는 하나의 AI 채팅을 사용한다.
- 다른 화면에서 진입하면 맥락 프롬프트가 자동으로 채워지고 전송된 상태로 시작한다.
- 입력창은 항상 보이고 AI 예상 답변은 입력창 위에 최대 3개만 제시한다.
- 빠른 답을 눌러도 이전 메시지를 삭제하지 않고 아래로 이어진다.
